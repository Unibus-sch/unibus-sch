# UNIBUS UI 정리: 기획과 검증

작업일: 2026-10-06  
브랜치: `codex/pwa-ui-optimization` (`1002c47`에서 수정)

## 방향

사용자가 이동 중 짧게 확인하는 앱이다. 첫 화면에는 노선, 운행 상태, 출발 시간, 다음 행동을 먼저 보여준다. 설명을 줄이고 상세 정보는 펼쳐서 읽게 한다.

- 색상은 남색 한 계열과 흰색·회색을 기본으로 한다. 카테고리마다 색을 추가하지 않는다. 오류와 카카오 로그인 등 기능상 의미가 있는 색은 유지한다.
- 숫자와 핵심 제목을 강조하고 보조 문구의 굵기를 낮춘다. 폰트는 사용자 피드백을 반영해 기존 Public Sans와 시스템 폰트 설정을 유지한다.
- 본문은 주로 15~16px, 보조 정보는 13px, 메뉴·작은 배지는 12px를 사용한다.
- 남색 운행 카드가 홈의 중심이 되게 한다. 같은 계열의 옅은 배경으로 다음 출발과 기능 아이콘을 강조하고, 얇은 테두리·여백·절제된 그림자로 층위를 만든다.
- 반복 설명, 노선 이름의 출발/도착 접두사, 불필요한 배지를 줄인다. 실제 운행·시연 구분, 시간표 주의 문구와 오류 정보는 유지한다.

## 참고한 디자인

- [Linear의 디자인 개편](https://linear.app/now/behind-the-latest-design-refresh): 강조와 장식을 줄여 내용에 집중하는 방향을 참고했다.
- [Notion](https://www.notion.com/product): 중립색과 타이포그래피 위계의 참고 사례로 확인했다.
- [Transit](https://transitapp.com/): 교통 이용자의 즉시 판단을 돕는 정보 구성의 참고 사례로 확인했다.

위 서비스의 화면을 복제하지 않고 UNIBUS의 모바일 이용 상황에 맞춰 적용했다.

| 화면 | 핵심 변경 |
| --- | --- |
| 홈 | 남색 운행 요약 카드, 두 개의 바로가기, 읽기 쉬운 출발 시간, 두 줄 공지 제목 |
| 공지 | 카테고리별 색을 제거하고 제목·날짜 중심으로 정리, 본문은 펼침 |
| 통학 | 출발·도착 지점과 시간을 우선 표시, 요금·소요 시간·설명은 상세에서 표시 |
| 셔틀 | 접힌 패널 높이를 줄여 지도 조작 버튼 확보, 상세 설명은 펼침 |
| 설정 | 개별 카드 대신 묶음 안의 행으로 정리, 선택 상태와 테마 규칙 통일 |
| 온보딩 | 짧은 소개와 바로 보이는 시작 버튼, 예시 노선 그림의 불필요한 실시간 표현 제거 |
| 로그인·회원가입 | 반복 설명과 장식 제거, 입력창·버튼 크기 통일 |
| 공통 | 하단 아이콘·레이블 통일, 다크 모드 아이콘 색 수정, 지도 모달의 Escape 닫기와 포커스 복귀 |

## 디자인 피드백 반영

최소한의 색상은 색상을 없애는 의미가 아니라 강조의 수를 조절하는 기준이다. 홈의 남색 카드와 같은 계열의 은은한 배경·작은 아이콘 영역·선택 상태를 복원했다. 홈 카드 배경은 추가 피드백에 따라 수정 전 파란색과 두 원형 장식, 16px 모서리, 원형 버스 아이콘 테두리로 복원했다. 정리한 문구와 글씨 크기는 유지하고 새로운 색상 계열은 추가하지 않았다.

## 폰트 피드백 반영

기존 Public Sans 로딩과 시스템 폰트 설정을 복원했다. 새로 추가한 폰트 목록과 글꼴 렌더링 강제 설정은 제거했다. 글씨 크기·색상·정보 배치는 유지한다.

## 검증

- TypeScript 타입 검사, 수정한 TSX의 ESLint 검사, `git diff --check` 통과.
- 기존 모바일 뷰포트·API 라우팅 테스트 4개 통과.
- Vite 프로덕션 빌드와 PWA 서비스 워커 생성 통과.
- 로컬 테스트 데이터로 390×844와 320×568에서 주요 화면, 긴 공지/노선 제목, 시간표 펼침, 통학 상세, 지도 모달 닫기, 밝은/어두운 테마를 확인했다.
- 320px에서 온보딩 시작 버튼이 스크롤 없이 보이고, 시간표가 한 열로 표시되며, 셔틀의 확대·축소·위치 버튼이 접힌 패널 위에 표시되는 것을 확인했다.
- 로컬 로그인 흐름을 테스트했다. 운영 로그인이나 외부 로그인·결제는 실행하지 않았다.

실제 지도 SDK는 로컬 인증 제한으로 지도를 표시하지 못했다. 실제 지도/위치 권한과 iPhone 설치형 PWA·가상 키보드는 별도 기기 확인이 필요하다. 배포는 하지 않았다.
